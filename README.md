# 🤖 SEO Content Agent

AI-агент для автоматического SEO-аудита контента сайта.

Агент сам обходит сайт, находит важные страницы, подбирает ключевые слова, анализирует частоту слов, оценивает соотношение полезного контента и «технического мусора», и даёт рекомендации.

## Что умеет

- **Автообнаружение страниц** — обходит сайт, находит категории, товары, бренды
- **Подбор ключевых слов** — AI предлагает коммерческие запросы для каждой страницы
- **Анализ контента** — считает частоту слов, сравнивает с ключевыми, оценивает качество
- **Графики** — визуализация по типу закона Ципфа (как у PR-CY)
- **Сохранение отчётов** — все аудиты хранятся в базе
- **Сравнение до/после** — видно, что улучшилось после изменений

## Быстрый старт

### 1. Получите API-ключ Anthropic

1. Зайдите на [console.anthropic.com](https://console.anthropic.com)
2. Зарегистрируйтесь (или войдите)
3. Перейдите в **Settings → API Keys**
4. Нажмите **Create Key**
5. Скопируйте ключ (начинается с `sk-ant-...`)

### 2. Разверните на Railway (рекомендуется)

1. Зайдите на [railway.app](https://railway.app) и войдите через GitHub
2. Нажмите **New Project → Deploy from GitHub repo**
3. Выберите этот репозиторий
4. В настройках проекта добавьте переменную:
   - `ANTHROPIC_API_KEY` = ваш ключ из шага 1
5. Добавьте Volume (хранилище) с mount path `/data`
6. Railway сам соберёт и запустит проект
7. Откройте сгенерированный URL — готово!

### 3. Или запустите локально

```bash
# Клонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/seo-agent.git
cd seo-agent

# Создайте .env файл
cp .env.example .env
# Впишите ваш ANTHROPIC_API_KEY в .env

# Вариант A: через Docker
docker build -t seo-agent .
docker run -p 8000:8000 --env-file .env -v seo-data:/data seo-agent

# Вариант B: без Docker
pip install -r requirements.txt
mkdir -p /data
uvicorn app.main:app --port 8000
```

Откройте http://localhost:8000

## Как пользоваться

1. Введите URL сайта (например, `https://tempus.ru/`)
2. Нажмите **▶ Запустить**
3. Агент работает автономно — можно уйти и вернуться
4. Результат: список страниц с оценками, графиками и рекомендациями
5. На вкладке **📁 Отчёты** — история всех аудитов
6. На вкладке **⚖ Сравнение** — выберите два отчёта и увидите разницу

## Структура проекта

```
│   ├── analyzer.py    # Подсчёт частоты слов

│   └── database.py    # SQLite хранилище
├── frontend/
│   └── index.html     # Веб-дашборд
├── Dockerfile
├── railway.json       # Конфиг Railway
├── requirements.txt
└── .env.example
```
